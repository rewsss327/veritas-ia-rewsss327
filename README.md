# 🫀 Cardiovascular Risk Prediction & High-Speed Inference Model

An ultra-fast machine learning pipeline built with Scikit-Learn's `HistGradientBoostingClassifier` designed to predict patient cardiac risk with high clinical accuracy and low latency.

## 🚀 Performance Metrics
- **Mean Cross-Validated Accuracy:** 98.03% (± 0.34%)
- **Mean Clinical Recall (Sensitivity):** 98.00% (± 0.76%)
- **Inference Latency:** ~8.91 ms

## 🛠️ Tech Stack & Features
- **Language:** Python
- **Libraries:** NumPy, Pandas, Scikit-Learn, Matplotlib, Seaborn
- **Engineering:** Feature interactions (Cardio Synergy, Age-Risk Ratio, Pressure-Age Interaction).
- **Validation:** 5-Fold Stratified Cross-Validation.
